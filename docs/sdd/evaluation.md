# RED Android Evaluation

## Review Rubric

- Spec: requirements are clear, testable, and mapped to `REQ-*`.
- Plan: files, tasks, agents, skills, risks, and verification are specific.
- Implementation: behavior matches spec and preserves Android lifecycle safety.
- Tests: cover changed behavior with the narrowest reliable automated tests.
- Contract: backend payloads, headers, errors, and tenant behavior are aligned.
- UX: mobile states, permissions, accessibility, and navigation are coherent.
- Closure: evidence is recorded and canonical docs are updated for high-impact work.
