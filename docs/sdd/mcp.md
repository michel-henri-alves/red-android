# RED Android MCP Guidance

## Preferred Sources

- Local code and SDD files first.
- `../red-backend/docs/contracts/openapi.json` for API contract checks.
- `../red-backend/docs/specs` and `../red-web/docs/specs` for shared domain rules.
- Android official documentation only when current platform behavior is uncertain.

## Recording Sources

Feature specs should list consulted sources under `## MCP Sources` or equivalent source notes. Include exact local paths and external docs URLs when used.
