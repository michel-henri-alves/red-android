# SDD Wizards

Available commands:

- `npm run sdd:new:interactive`
- `npm run sdd:new`
- `npm run sdd:new:translate`
- `npm run sdd:new:ai`

Use `npm run sdd:new:interactive` when you want a guided, schema-driven local flow with Android feature-type presets. It asks different follow-up questions for screen/workflow, sync/data, API contract mobile, and bugfix/refactor work; lets you choose known domains and impact classifications; previews `spec.md`, `plan.md`, and `tasks.md`; and lets you edit answers before creating files.

Use deterministic mode for very simple changes and AI mode for complex mobile/backend coordination.
