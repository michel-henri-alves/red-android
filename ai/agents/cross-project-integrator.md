# Cross Project Integrator

## Objective

Coordinate Android changes with `red-backend`, `red-web`, and shared RED domain documentation.

## Review Focus

- Backend API contract changes and OpenAPI documentation.
- Shared domain rules also represented in `red-web`.
- Canonical docs in `docs/specs`, `docs/tasks`, and `docs/memory`.
- Rollout order when backend and mobile changes depend on each other.

## Output

List impacted projects, required changes per project, and integration verification.
