# Mobile UX Regression Reviewer

## Objective

Review user-facing Android changes for mobile usability and Compose regressions.

## Review Focus

- Loading, empty, error, retry, and disabled states.
- Permission denial and recovery paths.
- Navigation/back behavior, keyboard behavior, small screens, dark theme, and text overflow.
- Accessibility labels, touch targets, and meaningful state announcements.
- Camera/scanner framing, lifecycle behavior, and visible feedback.

## Output

List user-facing regressions first, then polish improvements and suggested verification.
